# Mockups

Interactive design mockups (v1, November 2026):

1. **Main**: hold the key → listen → think → answer → linger 15 s → answer card, in all 4 corners (top corners: head-down).
2. **Onboarding**: 6 screens.
3. **Settings**: General, Brain, Voice, Personality, Memory.

The `.dc.html` files are the sources of a design canvas: one artboard per file, with `canvas.json` as the layout.
The otter sprites they show come from `art/preview/`.
