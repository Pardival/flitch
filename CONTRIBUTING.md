# Contributing to Flitch

Thanks for your interest! Flitch is in early development, so the best way to help right now is to:

- pick an issue labelled [`good first issue`](https://github.com/Pardival/flitch/labels/good%20first%20issue) or [`help wanted`](https://github.com/Pardival/flitch/labels/help%20wanted);
- give feedback on the [mockups and the otter](https://github.com/Pardival/flitch/issues?q=label%3Adesign);
- translate (English, French and Spanish first).

## Ground rules

- Be kind. See the [Code of Conduct](CODE_OF_CONDUCT.md).
- One topic per pull request. Link the issue it closes (`Closes #12`).
- Discuss big changes in an issue first. The architecture is described in [docs/architecture.md](docs/architecture.md). Decisions that change it get an ADR in `docs/adr/`.
- Code, comments, commits and issues are in **English**. Discussions in French or Spanish are welcome too.

## Development setup

Requirements: macOS 26, Xcode 26, [XcodeGen](https://github.com/yonaskolb/XcodeGen).

```bash
brew install xcodegen
xcodegen generate           # creates Flitch.xcodeproj (not committed)
open Flitch.xcodeproj
```

Core logic lives in the `FlitchKit` Swift package and runs without Xcode:

```bash
cd Packages/FlitchKit && swift test
```

## Code style

- Swift 6 with strict concurrency. Run `./scripts/format.sh` then `./scripts/lint.sh` before pushing; CI runs the lint too (config: `.swift-format`).
- `FlitchKit` must not import AppKit, except in the `FlitchStage` target.
- New behaviour comes with tests. Network code is tested against recorded fixtures, never live APIs.
- **Never log or commit secrets.** API keys and tokens only go through `CredentialStore` (Keychain).

## Art

- Sprites are generated by `art/*.py` (Python 3 + Pillow): `pip install -r art/requirements.txt`.
- The generated PNGs are committed, so building the app needs neither Python nor Aseprite.
- New characters are **packs** (see the architecture doc, §8). Art is CC BY 4.0 unless the pack says otherwise.

## Commit messages

Use a short imperative subject (`Add OpenRouter OAuth flow`), then explain the why in the body if needed.
